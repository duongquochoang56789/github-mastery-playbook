⚡ Vercel — Deploy 1 phút, hoàn toàn miễn phí

Vercel tối ưu cho Frontend / Static / Next.js. Git push lên main là app tự build + deploy.

Đẩy dự án lên GitHub

Config sẵn repo trên GitHub rồi:

bash — push
git init
git add .
git commit -m "Deploy to Vercel"
git remote add origin https://github.com/yourname/my-app.git
git push -u origin main

Deploy bằng Vercel CLI

bash — build
npm install -g vercel
npx vercel

Lệnh đầu cài CLI, lệnh thứ hai hướng dẫn đăng nhập + tạo project. Sau đó push lên main là auto-deploy.

✅ Xong! URL dạng app.vercel.app. Cách tốt nhất: vào Vercel Dashboard → Add New → Project → Import GitHub repo — mỗi PR còn có sẵn môi trường preview.

🖥️ VPS + Nginx + PM2 — Server Linux thật sự

Tự quản lý server, học Linux, tiết kiệm chi phí và hiểu đúng app chạy trong production thế nào.

Thuê VPS (Ubuntu 24.04, ~$4–6/tháng) rồi SSH

bash — connect
ssh ubuntu@YourServerIP

Cài Node.js 20 LTS + Git

bash — install
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs git nginx
node -v && npm -v && git --version

Clone code từ GitHub

bash — clone
cd /var/www
sudo git clone https://github.com/yourname/my-app.git
cd my-app
npm install
npm run build
⚠️ Nếu repo private, public clone sẽ lỗi. Giải pháp sạch: dùng deploy key (SSH) hoặc để GitHub Actions tự copy code (xem tab GitHub Actions).

Cài PM2 — chạy app chịu lỗi, tự restart

bash — pm2
sudo npm install -g pm2
pm2 start npm --name my-app -- start
pm2 save
pm2 startup   # tự động chạy lại khi reboot server
pm2 status

Nginx — proxy ngược, cấu hình 1 lần

/etc/nginx/sites-available/my-app
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
bash — enable
sudo ln -s /etc/nginx/sites-available/my-app /etc/nginx/sites-enabled/
sudo nginx -t          # kiểm tra cú pháp
sudo systemctl reload nginx
✅ App sống tại http://yourdomain.com. Thêm HTTPS miễn phí bằng Certbot: sudo certbot --nginx

🐳 Docker — đóng gói app, chạy ở bất kỳ đâu

Container = mã + môi trường + thư viện đóng gói sẵn → chạy giống hệt trên máy bạn, máy server, AWS…

Viết Dockerfile cho Node.js app

Dockerfile
FROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:20-alpine
WORKDIR /app
COPY --from=build /app/.next ./.next
COPY --from=build /app/package*.json ./
COPY --from=build /app/public ./public
RUN npm ci --omit=dev
EXPOSE 3000
CMD ["npm","start"]

Kỹ thuật multi-stage build: giai đoạn build có đủ devDependencies, giai đoạn chạy chỉ giữ bản tối giản → image nhỏ, an toàn.

Build + chạy local

bash
docker build -t my-app .
docker run -d -p 3000:3000 --name myapp my-app
curl localhost:3000

Docker Compose — app + database = 1 lệnh

docker-compose.yml
services:
  app:
    build: .
    ports: ["3000:3000"]
    depends_on:
      - db
  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_PASSWORD: changeme
    volumes:
      - pgdata:/var/lib/postgresql/data
volumes:
  pgdata:
bash
docker compose up -d --build
docker compose ps
💡 Push image lên GitHub Container Registry (GHCR): gh cr publish — image nằm ngay cạnh repo, tích hợp với GitHub Actions rất tự nhiên.

☁️ AWS EC2 — hạ tầng chuẩn doanh nghiệp

Chạy instance EC2 (Ubuntu, t2.micro — free tier)

Trong AWS Console: EC2 → Launch Instance → Ubuntu 24.04 → t2.micro → tạo key pair .pem. Nhớ mở Security Group: ports 22 (SSH) và 80/443 (web).

bash — connect
chmod 400 my-key.pem
ssh -i my-key.pem ubuntu@your-ec2-public-ip

Cài Docker trên EC2

bash
sudo apt-get update
sudo apt-get install -y docker.io docker-compose-v2
sudo systemctl enable --now docker

Chạy app bằng Docker Compose

bash
sudo git clone https://github.com/yourname/my-app.git /opt/my-app
cd /opt/my-app
sudo docker compose up -d --build
⚠️ Security: tắt password SSH (PasswordAuthentication no), dùng IAM với quyền tối thiểu, và đặt secret không nằm trong code.
💡 Muốn scale tự động thì chiều sâu hơn: ECS + Docker image từ GHCR + Application Load Balancer. Actions build image ì GHCR, ECS pull về chạy.

🤖 GitHub Actions — Auto Deploy mỗi lần push

Workflow nằm trong .github/workflows/deploy.yml. Cứ push lên main là Actions SSH vào server, pull code, build và restart — hoàn toàn không cần dùng tay.

Bước 0: Tạo deploy key (1 lần, chạy trên server)

bash — trên server
ssh-keygen -t ed25519 -C "actions-deploy" -f ~/.ssh/actions_rsa
cat ~/.ssh/actions_rsa.pub >> ~/.ssh/authorized_keys

Copy nội dung ~/.ssh/actions_rsa (private key) rồi vào repo GitHub: Settings → Secrets and variables → Actions → tạo secret tên SSH_KEY. Cũng tạo SERVER_HOST, SERVER_USER.

Bước 1: Workflow CI + Deploy

.github/workflows/deploy.yml
name: CI & Deploy

on:
  push:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
      - run: npm ci
      - run: npm run test
      - run: npm run build

  deploy:
    needs: test          # chỉ deploy khi test green
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Deploy to VPS
        uses: appleboy/ssh-action@v1.0.3
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SSH_KEY }}
          script: |
            cd /var/www/my-app
            git pull origin main
            npm ci
            npm run build
            pm2 restart my-app

Kết hợp Docker trong Actions

GitHub Actions + Deploy Docker
deploy-docker:
  needs: test
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v4
    - name: Login to GHCR
      uses: docker/login-action@v3
      with:
        registry: ghcr.io
        username: ${{ github.actor }}
        password: ${{ secrets.GITHUB_TOKEN }}
    - name: Build & push image
      uses: docker/build-push-action@v5
      with:
        push: true
        tags: ghcr.io/${{ github.repository }}:latest
    - name: Deploy to server
      uses: appleboy/ssh-action@v1.0.3
      with:
        key: ${{ secrets.SSH_KEY }}
        script: |
          cd /opt/my-app
          docker compose pull
          docker compose up -d --build
✅ Mỗi commit lên main: test → build → SSH → deploy. Dự án này cũng là 1 static web — bạn hoàn toàn có thể đưa nó lên Vercel hoặc GH Pages bằng cách này!
